# Maxperso
## Add-on Home Assistant : Enveloppe — Budget

Ce dépôt sert de dépôt d'add-ons Home Assistant. Pour installer :

**Paramètres → Modules complémentaires → Boutique → ⋮ → Dépôts**, ajouter :

```
https://github.com/MaximeLombSep/maxperso
```

Puis installer **Enveloppe — Budget** et le démarrer.

Détails, options et usage hors Home Assistant : [ADDON.md](ADDON.md).
